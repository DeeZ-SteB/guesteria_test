# Сценарій відео (5–7 хв)

Записувати з телефону (або DevTools 375 px) і з десктопа 1280 px. Перед записом: «Нова розмова» в асистенті, свіжі дати на 3–4 тижні вперед.

| 2 | 0:30–1:15 | Пошук Львова → результати → фільтр/сортування → ♡ | Живі ціни; обране зберігається в акаунті. |
